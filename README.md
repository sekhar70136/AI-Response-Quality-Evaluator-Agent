# AI Response Quality Evaluator Agent

This project evaluates AI-generated responses using three independent judge agents:
- Relevance Judge
- Accuracy Judge
- Hallucination Judge

## Features
- React frontend
- FastAPI backend
- Simple RAG-style retriever
- Beginner-friendly modular architecture

## Setup
1. Create a virtual environment
2. Install backend dependencies
3. Run the backend with uvicorn
4. Start the frontend with Vite
